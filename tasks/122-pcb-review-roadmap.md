# 122 / PCB 审查路线图（岳 2026-10-06 定的三步框架：DRC → 按模块 → 器件）

> 与原理图审查的本质区别（岳原话）：**layout 直接影响产品的电气性能和寿命**。
> 原理图审查回答「电路对不对」，PCB 审查回答「物理实现好不好」——同一个正确拓扑，
> layout 可以把它毁掉（噪声、发热、EMI、安规）。所以三步的权重完全不同：
> **第一步是门票，第二步是本体，第三步是收口。**

**架构决策（先行三条，整条路线图都建立在这上面）**：

1. **离线优先**：几何测量全走 `.epru` 离线解析（快、可单测、零真机风险）；
   bridge 只做三件事——触发 DRC、渲染图、导出。真机交互越少，审查越稳。
2. **工具出数、模型裁定**（原理图审查的同一分层）：测量库只产数字和坐标
   （间距/面积/线宽/环路），「合理与否」归规则阈值或模型判断。
   测量库必须对 fixture 板可复算，不许直接产出「结论」。
3. **模块清单一源**：PCB 审查的模块划分**继承原理图审查的 architecture.md**，
   不另起一份——两份模块清单必然漂移，而「这个模块在原理图审过什么、在 PCB
   审过什么」未来要写进同一份报告。（126 落地路径，2026-10-07 裁：architecture.md
   实测无模块章节，实为 **`modules[]`（页/连通性分组）打底 + `design-intent.blocks[].parts`
   覆盖**；无契约板自动退打底，不新造第三份清单。）
4. **host DRC 是连通性的地面真值**（岳 2026-10-07 盲审裁，原话：「DRC 都没报错，
   我们的工具报错，那说明是我们的工具有问题」）：host DRC 干净的板子上，离线几何
   报出的「短路/同层相交」一律先当工具洞排查，不当板子缺陷报；离线读数与 DRC
   矛盾时以 DRC 为准。
5. **PCB 检查必须桥接原理图检查**（岳 2026-10-07 裁，原话：「PCB 检查跟原理图检查
   不是两个分开的功能」）：PCB 规则的判定必须 grounding 在原理图事实上——器件是什么
   （value/mpn/器件类型）、每个脚在什么网、属于哪个模块，都从原理图模型取，
   几何测量只出数。**禁止「脚数 ≥3 就当 IC」这类不查原理图的启发式**
   （126b 把 MOS 管当 IC 查去耦，就是这么犯的）。

## 第一步：DRC 检查（门票）

做什么：

1. 触发 host DRC（`pcb_Drc`），收集全部致命/错误/警告，落结构化 findings
   （checkup 的叶子管线现成）。
2. **裁定纪律同 ERC**：逐条分类有益/有害/无害，记录理由。
3. **PCB 特有、原理图没有的一层——规则集元审查**：DRC 全绿不代表板子对，
   只代表它过了当前这套规则。要核对规则值本身：最小线宽/间距/孔径/阻焊桥
   是否按目标板厂工艺设的（嘉立创免费工艺 vs 付费工艺限值不同）。
   规则设错了，DRC 越绿越危险。
4. 基线化：findings digest 入册，回归对比（本次 vs 上次）。

验收：对一块真板跑出结构化 DRC 报告 + 规则集核对清单；0 致命 0 错误才放行第二步。

## 第二步：按模块检查（重中之重，权重最高）

两层：**通用层**（每个模块都过）+ **模块特定层**（规则包，按模块类型启用）。

### 通用层（10 项，每项标注数据源与自动化级别）

| # | 检查项 | 量的是什么 | 数据源 | 判定 |
|---|---|---|---|---|
| 1 | 关键器件布局约束 | 去耦电容贴芯片电源脚、反馈分压近 FB、晶振贴 MCU、驱动贴 MOS 门极——逐对距离 | epru | 规则（距离阈值） |
| 2 | 功率环路面积 | 输入电容→开关→变压器/电感→地 的环路包围面积 | epru | 工具出数，模型裁定 |
| 3 | 回流路径 | **按层叠分型**（岳 2026-10-06 裁：不同层数板子作用不同，需再论——框架见下） | epru（层叠读出 + 铺铜连通性 + 跨分割检测） | 工具出数，模型裁定 |
| 4 | 载流能力 | 每网最小线宽 vs 电流（IPC-2221）、过孔并联数 | epru + 电流需求（architecture.md） | 规则 |
| 5 | 压降 | 大电流路径铜电阻估算（1oz，长/宽） | epru | 工具出数 |
| 6 | 热 | 功耗器件的散热铜面积、热过孔阵列、与热敏器件间距 | epru + 功耗（事实库） | 规则+模型 |
| 7 | EMI | SW 等 dV/dt 节点铜面积最小化、di/dt 环路、晶振下方净空、噪声源离板边/敏感信号距离 | epru | 规则+模型 |
| 8 | 安规/隔离 | 初次级爬电距离与电气间隙（按工作电压/污染等级查表）、隔离槽存在性 | epru（两网跨层最小间距） | 规则（阈值查表） |
| 9 | DFM | 器件间距、焊盘尺寸、丝印压焊盘、极性标记 | epru | 规则 |
| 10 | 可测试性 | 测试点、烧录口可达性 | epru | 清单核对 |

### 模块特定层（规则包，优先级即开发顺序）

1. **电源（LDO/Buck/Boost/反激）**：输入输出电容贴芯片、FB 从输出电容端取样且
   远离开关节点、功率环路最小、散热铜皮、（反激）初次级隔离带（阈值先按
   **IPC-2221** 简化表，岳 2026-10-06 裁）与 Y 电容位置。
   ——反激是我们最熟的电路，rule 包从它开始。
2. **MCU 最小系统**：每个电源脚一颗去耦且就近、晶振就近+下方净空层、复位/启动。
3. **功率驱动/FOC**（岳本行）：栅极驱动环路短、**电流采样开尔文连接**、母线电容
   贴功率管、采样信号远离开关节点。——岳最能验收的模块，放第三批但权重最高。
4. **接口/连接器**：ESD/TVS 贴接口、共模电感位置、信号走向。

### 回流路径的讨论框架（岳裁「需再讨论」的落点，**未钉死**）

回流检查对不同层数的板子**不是同一件事**，先按层叠分三型，开工前与岳逐型对齐：

| 层叠 | 回流的物理形态 | 要查什么 | 测量原语 |
|---|---|---|---|
| **单/双层** | 没有完整地平面，回流走**显式地线/铺铜**的最近物理路径；功率板上它同时是压降与发热问题 | 高 di/dt 网（SW/栅驱/采样）的地回路宽度；信号是否跨越地铺铜裂缝（回流被迫绕远=环路面积暴增）；地网络的瓶颈截面 | 铺铜连通性 + 瓶颈宽度 + 缝跨检测 |
| **四层（SIG/GND/PWR/SIG）** | 有完整参考平面，回流自动走信号**正下方**的镜像路径 | 信号换层处有没有**地过孔伴随**；参考平面分割处有没有跨缝走线；电源平面对大电流网的载流 | 过孔伴随率 + 跨分割走线检测 |
| **功率/混合信号**（不限层数） | 大电流回流与小信号回流必须分家 | 功率地（PGND）与信号地（采样/MCU 地）是否单点汇合；采样信号是否与功率回流共路径（共阻抗串扰——FOC 低边采样的命门） | 地网分区 + 共路径段检测 |

待论问题（开工前找岳对齐）：①~~毕设 FOC 是双层还是四层~~ **已裁（2026-10-07）：四层板**
——主用「四层（SIG/GND/PWR/SIG）」表，单/双层表留给 PCB1 类双层板；
②模地/数地分型在 FOC 板上怎么落到检查项；③「共路径段检测」的阈值怎么定（②③ C 阶段开工前再对齐，不挡 B）。

### 为什么第二步是重中之重（写进报告生成器的排序依据）

第一步 DRC 过，只说明「能造」；第二步决定「好不好活」——噪声、发热、EMI、
寿命全在这里。报告产出时第二步的 finding 严重度权重最高，且第二步不完成
整板审查不判通过（对应原理图侧的 `mayClaimPassed` 纪律）。

## 第三步：器件检查（收口）

1. **封装一致性**：原理图/BOM 封装 vs PCB 实际焊盘（epru FOOTPRINT 段对账）。
2. **降额的物理层**：耐压/功率 ↔ 封装尺寸（岳的实例：RCD 电阻 0603 换
   0805/1206 串联承担电压）；与原理图侧 datasheet 事实库打通。
3. **极性与方向**：极性器件方向标记、同类器件方向统一（生产工艺）。
4. **丝印**：位号可读、不压焊盘、方向一致。

| **E. 器件检查 + 报告整合** | 封装/极性/丝印检查；原理图+PCB 合成一份审查报告 | 一键出整板报告（ERC+DRC+模块+器件） |

依赖关系：A 独立可先做（管线现成，只差触发）；B 是 C/D 的地基；
E 的封装对账可以提到 C 之后立刻做（数据源现成）。

**B 收口记录在案（125，详目见 PROGRESS）**：①铺铜对异网的 keepout void 不在几何模型里，
落在铺铜轮廓内的异网元素按「不可测」剔除而非报 0；②POURED 的 path 是 1:10 缩放+父记录
相对坐标+`pourFill` 数组，解析器暂丢空，连通性基于 FILL/POLY——C 阶段若要真实铺铜结果
（内含避让空隙），需先做 POURED 解析增强；③毕设FOC 多处同层 overlap 疑似解析器网名归属，
未钉锚点，留给规则层/模型裁定。
