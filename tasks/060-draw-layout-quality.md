# 060：画法编译器布局质量批——外围归属分侧 + 重复脚视觉义务

057 真机验收（059）全绿后，岳亲眼复核 `outputs/057_live/e1b/render.png` 的裁决原话：

> 器件摆放问题不小，虽然连上了，但是有一个 VOUT 空悬（负责散热的大引脚），而且电容没必要在一侧摆放。

电气连接全对、可读性九条+页级八条全过，**但工程师一眼不接受**——这正是 052 说的"可读性验收要从第一天执行"抓到的那类缺口：现在的闸能证明"合法"，证明不了"像工程师画的"。本批修两处，都是语义布局层的缺口，不是坐标调参。

## 一、外围归属分侧（电容没必要在一侧摆放）

LDO 文法的 `sidePreferences`（input/output 侧）只决定**支路从哪侧出**，不决定**电容贴哪侧**。实测渲染里输入电容 C8(100nF) 与输出电容 C9(22µF) 摆在同一侧——工程师期望：**输入电容靠 VIN 脚一侧、输出电容靠 VOUT 脚一侧**（外围归属，052 词汇表里的 peripheral ownership）。

- **语义布局层**：`ldo` 文法的语义约束加"电容归属其服务的引脚侧"——输入电容与 VIN 脚同侧就近，输出电容与 VOUT 脚同侧就近。`rc`/`voltage-divider` 自查同款缺口（RC 的电容归属输出节点一侧）。
- **可读性闸**：`readability` 加一条页内检查（硬约束还是软指标，执行者带实测数据回来主代理裁）：去耦电容的中心与其归属引脚侧的偏离超过阈值 → 点名。不许做成"全局一侧禁放"的铁律（052：反馈/总线/高扇出需要不同画法）。
- **验收**：E1 配方重编译，渲染图人眼（主代理亲看）——C 输输入侧、C 输输出侧；既有 053B/056 场景几何哈希**允许因此变化**，但必须逐场景申报前后差异（哪件挪了、为什么更符合归属），主代理裁。

## 二、重复脚视觉义务（VOUT 散热脚空悬）

AMS1117 的 4 号脚是重复 VOUT（散热大焊盘脚）。055 G1 后文法上"任一同角色脚连网即算已连"，所以 4 号脚写进 `nc[]` 合法——但**视觉上一个空悬的大引脚**不像工程师的手笔。

- **待岳裁（本批执行前先问）**：重复脚的默认画法应当是——
  - a) **默认接上**（同网短接到已连脚/网，电气等效，散热脚接地电流路径也是工程师惯例）；nc 变成显式例外；
  - b) 保持 nc 但**视觉表达**（引脚上打"x"标记或在标签注明 NC）；
  - c) 维持现状（文法合法即可，视觉不管）。
  
  主代理倾向 **a)**（工程师画 AMS1117 几乎不会空悬 TAB 脚），但 this is 岳的电路判断，不是工具判断。
- 实现侧（裁决后）：`ldo` 文法对同角色多脚出"并联短接"布线义务 + `drawcompiler` 支持同件两脚短接线（不触发"同角色两脚落两个网=circuit-invalid"——同网，不冲突）。
- **验收**：E1 配方重编译渲染，VOUT 两脚都接线；`nc` 写法的旧场景行为不变（显式 nc 仍是合法陈述）。

## 三、旗标旋转整体反 180°（岳裁决：都要翻转 180°）

059 真机渲染复核发现：**所有 GND 旗标在画布上是倒的**（bar 由窄到宽朝下 = 翻转 180°；U4.1 那颗侧指的也同样反）。
根因（主代理已查证）：`engines/drawcompiler.py::_flag_rotation` 的罗盘映射与立创库里电源符号的自然姿态
**反了 180°**——映射假设"引脚朝下 → rotation 180°"，而立创 GND 符号自然姿态是连接点在上、bar 向下渐窄
（引脚朝下应 rotation 0°）。`outputs/057_live/e1b/plan.page.json` 实测值：三颗引脚朝下的 GND 全 180（应 0）、
U4.1 侧指 90（应 270）。**为什么离线没抓到**：svgpreview 用与编译器同一套错误约定画理想化旗标，
预览自洽但与画布真实符号不符——预览保真度缺口。

- **修法（裁决已定）**：映射整体 +180°——(0,1)→180°、(0,-1)→0°、(-1,0)→270°、(1,0)→90°。
- **svgpreview 同步修**：预览的旗标字形约定必须与立创库符号自然姿态一致（连接点在 stem 尖端、bar 在反侧
  渐窄），从此 预览 ≡ 画布。加一条测试钉住"GND 旗标在引脚下方时 rotation=0 且预览画成悬挂形"。
- **哈希再基线（申报制）**：旗标 rotation 进 plan 几何摘要 → 053B 12 场景 / 056 8 场景 / 057 页级场景的
  几何哈希**全变**。这是本批唯一被允许的批量哈希变化：逐场景确认**只有**旗标 rotation 字段变、其余逐字节
  相同，列表申报，主代理裁。
- **真机复验**：E1 配方重 compile→plan→apply（新页），渲染 PNG 主代理+岳亲眼确认旗标全部正挂；
  旧页用 `draw discard` 清场后重落。
- **追溯**：054 起的真机落图旗标全是倒的（当时没人放大看）——PROGRESS 本条注明，不回改历史记录。
