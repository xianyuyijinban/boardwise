## 偏差① 电源旗的位置（图中①）

| | 位置 |
|---|---|
| 你的样板 | +24V 旗在**顶轨左端**（背向连接器的那一端），竖直 |
| 我们现在 | +24V 旗在**顶轨右端、连接器脚旁**（入口处），竖直 |

**为什么是现在这样**：挂旗的选点规则（`drawcompiler._power_flag_pin`，069 批）是四种画法共用的公共逻辑，
今天它选中了入口脚。你的样板要求的是「挂轨的远端」。

**改动代价**：直接改公共选点会让既有 39 张场景回归图全部移位（我们的硬约束是不许动旧图），
所以正确做法是 power-entry 语法声明一句「轨旗挂远端」，只对它自己的轨生效。含测试约半天。

**选项**：
- A. 挂远端（对齐你的样板）
- B. 挂入口侧（保持现状，也是常见画法）
- C. 两端都挂

## 偏差② 底轨没有接地符号（图中②虚线圈）

| | 底轨 GND 的表达 |
|---|---|
| 你的样板 | 底轨左端有一个**接地符号**（线从符号引下来接底轨） |
| 我们现在 | 底轨就是一条实体横线，**一个接地符号都没有**（页级场景跨模块时 GND 才会出旗） |

**为什么是现在这样**：语法承诺的是「地是实体线、表达统一」，没人承诺过「线上要有一个出处符号」。

**改动代价**：和①同一条公共路径，同一个声明式开关可以一起带出来。①②都选 A 的话总共约半天到一天。

**选项**：
- A. 实体线 + 远端一个 GND 符号（对齐样板）
- B. 纯实体线（现状）
- C. 实体线 + 两端各一个

## 偏差③ 支路顺序（图中③箭头）

| | 从连接器往左的顺序 |
|---|---|
| 你的样板 | D1(TVS) → C115 → C116，**TVS 贴着入口** |
| 我们现在 | C115 → C116 → D1，**TVS 离入口最远**（按位号字典序） |

**为什么是现在这样**：连接器、TVS、电容在电路上完全同构（都是跨两条轨的两脚件），
而语法红线（053 §6）不许看位号前缀、值、封装名——所以它不知道哪颗是 TVS，只能按位号排。

**若要让 TVS 靠入口**：得有一条声明通道（比如 CircuitSpec 里给支路写顺序提示或子角色），
语法才能既不破红线又排出你要的顺序。代价中等，不建议现在做。

**选项**：
- A. 不管（同构支路谁先谁后不影响读图）
- B. 加声明式排序提示（留到设计意图通道做起来时再说）

## 不用你裁的两项（已钉测试，089 真机落图会避开）

1. 宽轨（≥4 个成员）标 mainPath 时，页级编译器画线、可读性检查器却当总线拒绝 → 整页 0 候选。
   两边判据不一致是既有缺陷，修法在公共路径，归后续批次。
2. 声明页面尺寸时，锚点的格点吸附最多能把图往外顶半格（2.5 单位），1170×825 的页面对样板图报「放不下」；
   不声明页面就正常。同样是既有缺陷。

③**A**（不管，等设计意图通道）。

## 裁决结果（2026-10-02 岳，逐字）

1. **偏差①：挂在入口处，保持现状**，不照样板改。→ 无代码改动；088 已钉的「今天是这样」测试从「待裁决」转为「裁决确认」。
2. **偏差②：加一个接地符号**（原话：「真实体现得很乱」——底轨要有一个、且只要一个出处符号）。
   位置定为**底轨远端**（背向连接器那端，与样板一致；旗按①在入口端，两端各一个标记）。实体线保留。
3. **偏差③：按样板做**——TVS/二极管不许乱排，**TVS 必须最靠入口**（原话：要及时把电压尖峰泄下去）。
   机制：语法不看位号/值/封装（053 §6 红线不动），由 PresentationSpec 新增可选 `modules[].branchOrder`
   （从入口端往远排列支路位号）声明顺序；缺省保持位号序（既有行为不变）。写 spec 的模型读得到器件值
   （SMCJ28CA 是 TVS 料号），顺序意图由它声明、语法负责执行与核验。
