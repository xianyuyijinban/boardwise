## 岳的裁定（逐条）

1. **MOS 管没有去耦**——Q1/Q3/Q7（MCAC53N06Y-TP）被 `pcb-decap-distance` 当 IC 查去耦是误报。
   修法方向：IC 判定走原理图器件事实（value/mpn/器件类型），禁脚数启发式。
2. **U6 不是 +24V 网上的，是 5V 转 3.3V 的**（岳陈述）——但 PCB1 文档里 U6 有 12 焊盘、
   网络是栅驱签名（+24V×3/PGND×3/GHC/GLC/SHC/SLC/IC±）。**127a 正在对质**：
   原理图侧说它是 LDO → 解析器 PAD_NET 归因 bug 实锤；两侧一致是栅驱 → 出示证据请岳复核记忆。
3. **0.0mil 贴脸/同层相交一律先当工具洞**（host DRC 干净的板上）。待 127a 逐对查网络归属：
   同网 → 规则补同网豁免；跨网 → 归因 bug。
4. **GND/PGND（0V 对 0V）不报间距**——两地单点汇合是设计意图，规则要豁免同压网对。
5. **大体积电容的距离要算本体**（岳原话：「330μF 电解本身就有 7 毫米了」）——
   a) 度量层补「本体到本体」距离（需查封装段有没有本体/丝印轮廓数据，没有就如实记录缺口）；
   b) 规则层把电容分角色：**bulk（≥10μF 电解/钽）与 HF 去耦（≤1μF 陶瓷）分开**，
      候选池、阈值、布局判据都不同（bulk 靠近电源入口/大电流回路，HF 贴芯片脚）；
      容值从原理图 value 字段读，不许猜。

## 127b 修复清单（任务书级，子代理执行）

> 前置全部就位：127a 取证（定性见上）、128 分类器统一（823d788 已推）。
> 修复完重跑毕设FOC（1.1.0）夹具验收出第二轮矩阵；**1.0 工程的终验等岳导出**。

1. **焊盘有效层语义（测量层根修）**：`PadGeometry` 加 `effective_layer_ids`——
   SMD 焊盘 = 元件所在面（`COMPONENT.layerId`）；带孔（plated）焊盘与 layerId=12
   （Multi-Layer）= 全部铜层。原 `layer_id` 字段保留不动（125 的钉不受影响）。
   规则全部改用有效层。**回归钉**：127a 那九对顶×底配对修后必须全部消失。
2. **`pcb-component-spacing`**：同网焊盘对豁免（同网相触是设计本意）；
   跨面配对（顶×底）直接不比（物理上不可能相碰）。
3. **`pcb-decap-distance` 判定桥接原理图事实**（岳裁定 1+5 落地）：
   a) IC 判定走原理图器件事实——原理图模型里该件的 DEVICE tags/类型
   （连接器/排针/晶体管/被动件不查；U6=排针、Q1=MOS 修后不再触发）；
   b) 电容分角色：容值从原理图 value 读——≥10μF 或电解/钽 = bulk（不进 HF 去耦
   候选池；某 IC 只有 bulk 候选时报 INFO「只有 bulk，无 HF 去耦候选」），
   ≤1μF 陶瓷 = HF 去耦候选。
4. **`pcb-voltage-spacing`**：双地/同压网对豁免（GND↔PGND 这类 0V↔0V 不报）；
   有效层修复后重叠假阳性应自然消失，测试钉住。
5. **回归验收**：毕设FOC 夹具全量 checkup，对比 126 矩阵——预期：19 条假阳性清零、
   Q1/Q3/Q7 去耦消失、U6 全消；真 finding（同侧密集排布 8 条、DRV8350 去耦等）保留。
   差异表写进回报。

### 与任务书预期的一处**不符**，需岳复核

任务书写「真 finding（同侧密集 8 条、DRV8350 去耦 275.7mil）保留」。实测：

  Board3 原理图里 `U2` 是 **`PZ2.54-2*6` 排针**（栅驱信号引出排针），DRV8350 是
  **Board1/PCB1 的 U2**（`DRV8350SRTVR`，33 脚）。126 的那一行是通过位号
  `U2` 跨板匹配到的，两块板各有一个 U2。**审查对象错了，不是解析错了**
  （与 127a 对 U6 的结论同型）。修法：IC 判定走器件事实 → PCB3 的 U2 是排针，
  不再触发；且 C115 是 330µF 电解，按 3b 也不该进 HF 池。
