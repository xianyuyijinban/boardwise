# 039 批②：审查流程升级（手册闸 / 警告分诊 / 审美开关）

> 依赖：039 批①（parts 工具链 + `facts_verified` 闸）落地后开工。
> 本批的意图全部来自岳 2026-09-25 晚的三条口述指令，逐条落成了下面的工作项。

## 岳的原话（裁决依据，不许走样）

1. 「缺数据手册的话，审查应该停下来。获取途径：① 工程师给；② AI 在立创 EDA 里找到器件手册；
   ③ 官网找。不然无法判断原理图画得好不好。」
2. 审查三步：① 查 ERC，警告先看并记录；② 分模块，**警告所在模块优先**，逐条判警告
   **有益/有害/无害**并记录；认识就直接分析，不认识就搜手册；③ 分析整图布局美观度。
3. 「审美做成一个开关，默认关闭（我们测试时打开）。初次有一些配置需要用户去做，
   把审美设置做成选项让用户选。」

## 工作项 1：手册闸（器件级，揉进模块循环，不是前置总闸）

- checkup 报告把 `unknown_parts` 升格为一等公民「**未审器件**」节：designator / mpn /
  缺哪些 fact / 三通道各自的结果（给了没有、立创找到没有、官网搜到没有）。
- SOP（SKILL §3，主代理改）：模块循环里遇到无事实器件 → **不许跳过、不许涂绿** →
  按三通道获取手册 → 拿到则当场提取事实继续审；三通道全灭才进「未审器件」。
  **该节非空时 AI 禁止宣称"审查通过"**，只能说"DRC/连接性已审，N 颗器件缺手册未审"。
- 事实分级：会话内刚从手册提取的事实**当场可用**，报告标注"依据：本次提取、未经入库核验"；
  沉淀进 `parts.json` 必须走批①的 verified 闸（岳审 git diff）。
- 新命令 `boardwise parts fetch <mpn>`：立创通道**自动解析**——从库条目/raw 提取拿
  `datasheetUrl`/`datasheetPdfUrl`，下载 PDF 到 `.tmp_datasheets/`（gitignored），
  提取候选事实（隔离 venv `pypdf` 的老约束沿用批①），写成 `facts_verified: false` 候选。
  工程师给手册 = 同命令加 `--file <本地PDF路径>`。官网通道不归 CLI（AI 用 WebSearch），
  但 fetch 的失败输出要给出建议查询词。
- 探测前置：立创通道的 URL 在 raw 条目里的覆盖率要先量（94 条里多少带 `datasheetPdfUrl`），
  覆盖率写进交卷。

## 工作项 2：ERC 警告分诊 + 警告→模块归属

- 报告 schema 加 `warning_triage[]` 槽位：每条警告 = {文本, 页/模块归属, verdict:
  有益/有害/无害（AI 填）, 理由（AI 填）}。CLI 产空槽 + 证据，AI 在 SOP 里逐条填。
- **警告所在模块优先审**：模块节按"含警告优先"排序。
- **先探后写**（坑 17：ERC 计数 host-wide）：ERC 叶子能不能干净归属到页/模块，
  真机 probe 一次（只碰 test 窗）；归不了就降级为"警告按页列出、模块归属由 AI 看图判"，
  不许编归属。

## 工作项 3：审美评分（默认关的开关）

- 五轴标尺：**拓扑可辨 / 流向明确 / 文字可读 / 分组合理 / 网络标识规范**——
  与路线图 M2 的绘制可读性标尺同一把尺（审查数据就是将来 M4 绘制的评测标尺，岳的战略意图）。
- **开关默认关**。三层落地：
  1. 持久配置：`%USERPROFILE%\.boardwise\config.json` 加 `review.aesthetics`（boardwise 第一个
     用户级配置项）；新命令 `boardwise config set review.aesthetics on|off` + `config get` 回读。
  2. 单次覆盖：`checkup --aesthetics / --no-aesthetics` 优先于配置。
  3. 初次引导：SKILL SOP 写死——AI 首次为用户服务时问一次"要不要开布局审美评分
     （需要视觉能力强的模型，会多看几张画布图）"，把选择写进配置；不问第二次。
- 开 = 报告加 `layout_review` 节（五轴各 1–5 分 + 一句证据，逐页 PNG 已现成）；
  关 = 该节**不出现**（不是空节——不存在与存在但空是两回事）。
- 模型分层纪律：开关开着但驱动模型无视觉能力时，SOP 要求标"跳过：模型不具备视觉判断力"，
  **禁止编分数**（弱模型假装看出好坏比不评更害人）。

## 测试与验收

- 手册闸：`parts fetch` 立创解析成功/无 URL/--file 本地三形态；未审器件节非空时
  报告结论语不许含"通过"；候选事实 verified=false 不驱动规则（批①的闸复用）。
- 警告分诊：槽位 schema 断言；模块排序"含警告优先"一例；ERC 归属 probe 结果如实记录。
- 审美开关：默认关（config 缺省）→ 报告无 `layout_review` 节；`--aesthetics` → 有；
  config on + `--no-aesthetics` → 无（单次覆盖赢）；`config set` 持久化往返。
- eval 红线照旧：前后各跑一遍，delta 逐条解释，高优精确率/召回不降。
- 变异 ≥2：开关逻辑反了 / 未审器件节被吞。三线全绿。真机只碰 test 窗（本批只有
  ERC 归属 probe 需要真机，其余全离线）。
