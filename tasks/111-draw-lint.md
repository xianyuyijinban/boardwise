# 111 / draw lint 可读性检查器（岳 2026-10-04 裁「可以」）

背景：110 反激暴露的最大工具缺口——「压线/重叠/间距」缺陷全部纯几何可判，
现在靠人眼复审。**本批把它变成机器闸**：`draw lint --page P1`，
对 live 页几何快照跑谓词，违规分级报告（#55 同款 ERROR/WARN/INFO）。
**验收两条可测量**：110 P1 修前快照的已知缺陷**全中**；已验收页 P22/P23/P24 **零误报**。
全部离线（live 页只读快照允许）；plan 侧（编译期 lint）归后续批，不在本批。

## 谓词表（九条，每条对应 110 的真实缺陷）

| # | 谓词 | 级别 | 110 对应缺陷 |
|---|---|---|---|
| L1 | 文字压线：文字框 × 任何线段（自有附着点/同网标签的引线除外） | ERROR | ST 横线穿过 "VCC" 文字 |
| L2 | 文字压字：两文字框相交或间距 < T | ERROR | HVDC/VDC 叠 COMP |
| L3 | 文字压器件：文字框 × **别的**器件体框（压自己器件=099c 同款豁免） | ERROR | CS_FILT 竖排贴器件 |
| L4 | 线穿器件：线段 × 器件体框 / × **别网引脚**（非端点） | ERROR | 四段中途穿引脚（并可预警宿主并线坑） |
| L5 | 同网重复标注：同网 label+flag 或同区域（距离 < T2）多 label | ERROR | 反馈区反复标 |
| L6 | 交叉计数：无结点线×线交叉 | INFO | CS_FILT×HVDC 十字 |
| L7 | 间距：标签↔线 / 引脚↔线 < T3 | WARN | U3 区标签拥挤 |
| L8 | 旗标朝向：电源/地旗非竖直（坑 42/43 的尺子可借鉴） | ERROR | 岳的旗标规矩 |
| L9 | 版面分布：页幅利用率 / 模块间距 | INFO | 左下 60% 空白 |

阈值 T/T2/T3 从验收页实测标定（P22/P23/P24 零误报是硬约束——先量它们的自然
间距分布，再把阈值定在分布外），并在代码里写明出处。**零误报优先于检出率**
（误报会把岳淹掉，漏报还有人眼兜底）。

## 输入与文字几何

- 页面快照走 `sch.geometry` / `sch.readback` 既有通道（只读）；线段/引脚/器件框
  棒B 的 canvas_evidence 正交分解做法可借鉴（`outputs/110/b/`）。
- **文字框**：若快照不给文字范围，用「锚点 + len(text)×字符宽×字号」估算
  （从一张已知渲染实测一次字宽字号，常数写明出处并标 estimate）；
  位号/值/netlabel/旗各算各的。

## 夹具与验收

1. **合成夹具**（每谓词至少一正一反两个最小页面）：构造小 dump 断言命中/不命中。
2. **真实零误报钉**：P22/P23/P24 三页（已验收）live 快照或 `outputs/` 既有 dump——
   **零 ERROR/WARN**（INFO 只报不算）。
3. **真实检出钉**：110 P1 修前态——若 `outputs/110/{b,d}/` 有对应几何 dump 直接用；
   没有就用合成夹具覆盖那 ~10 处缺陷类别，并在报告里如实说明哪几类只有合成证。
4. 变异 ≥2 组（cp+sha256）：M1 摘掉 L1 → 文字压线类漏报；M2 阈值改紧 →
   验收页必须出误报（反向证明阈值标定有效）。
