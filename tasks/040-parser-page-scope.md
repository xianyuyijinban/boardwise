## 背景（039d 调查定论，证据 `outputs/039d_c115_net_attribution.txt`）

岳的毕设板导出件和板子本身**都没问题**——"C115 两端 AGND / U5.5 落 AGND"全是我们的解析器 bug
（主代理此前对岳的误报已收回）。真凶两条，消融实验自证（§7.2，D 列与铜层 PAD_NET 逐脚一致）：

- **R1 主犯**：`schematic.py:900` pin 节点键 `("p", designator, number)` **不带页**。多板工程
  （该件 3 BOARD/3 SCH/3 PCB、30 个跨页重号位号、70 个共享 pin 键）的三张网表被焊成一张图，
  命名取字典序首 → AGND。
- **R2 共犯**：`schematic.py:372-378` 凡带 `lineGroup` 的 LINE 一律当导线，从不查 WIRE 头；
  一条无头图形段把 +24V 轨与 PGND 轨短接 → 整排 330uF"两端同网"。
- **影响面**：多板工程全中（毕设板 30/70/2 处幻影桥、高速电机控制器 17/43/4 处）；
  单页黄金夹具全不发作——三线全绿而真实工程读数离谱的原因。
