# 111 增补备忘（岳 2026-10-04 编辑器 DRC 后的观察，111 交卷复验时并入或归 112）

岳在编辑器亲跑 DRC（0 fatal / 0 error / 22 warn / 15 info）+ 目视后裁定：
**反激 P1 不再手工磨了，等工具优化后重跑一版**。以下四条并入 draw lint 规则表：

1. **L10 出界检查（新）**：元素框（器件/线/文字/旗）超出图幅框即 ERROR。
   实证：+12V 旗在右缘 (1160,325)（图幅 1170 宽）、R19 顶部贴近上框。
2. **L5 增强（同名导线段）**：宿主 DRC 报「导线有多个网络名 LED_A、LED_A」——
   具名短线技术的副产品：同一连续导线的多个分段各自命名。**一条连续导线只许一段命名**。
3. **L6 交叉升级**：岳目视「很多线段存在不必要的交叉」——交叉数超阈值或存在局部
   替代（挪一格就不交叉）时从 INFO 升 WARN。
4. **坑 27 可破**：`sys_Log` 有 `find`/`export`（类型包实测）——宿主 ERC 的逐条文本
   可以从日志通道捞（岳的面板 22 条全文证明文本存在）。做一个 `sch.drc_detail` 动作
   或 checkup 阶段补逐条，把「0 error / N warn 无文本」终结。

另（不进 lint，归绘制纪律）：落件后写 Value 的格式与器件自带属性不一致会触发宿主
「属性与供应商编号不匹配」warn（R3/R15/R18/R19 实证）——写值格式规范化归下一批。
