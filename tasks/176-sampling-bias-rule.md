# 176 采样链偏置电压检查规则（issue #76，岳 2026-10-12 准开）

来源与语义草案：issue #76 全文（`gh issue view 76`）。岳裁原话：「凡是采样，尤其是交流部分的采样，都要去查它有没有偏置电压。」台架实证：ROBOT ctrl FOC 板无偏置上不了机，飞线加偏置电阻后正常。

## 规则语义（issue 草案，岳已裁，无需再议）

- 识别采样链：毫欧级分流电阻一端接地/母线、另一端进 MCU ADC 脚或运放。
- 交流/双向场景（相线串联采样等）无偏置 → **ERROR**。
- 低边分流直连 ADC、无偏置无滤波 → **WARN**（台架实证上不了机）。
- 有偏置（分压至 VREF/2、或运放带偏置参考）→ 过。
- 低边+偏置但无滤波 → INFO 建议补 RC。

## 取证锚（ROBOT ctrl FOC 实测拓扑，规则必须抓到）

R4/R5 两颗 100mΩ：下端直接落地，上端（U+/W+）直连 U1.21(PA7)/U1.24(PB0)；
无运放、无偏置、无 RC、无串阻；VSSA 经 R8(0Ω) 直连 GND。→ 两条 WARN。

负面锚：带运放偏置链的板不许误报（用夹具里有的板实测核对，写进证据）。

## 落点与边界

- 原理图侧规则包（rules/ 下照 path-ldo-dropout 等既有规则的形状：id/severity/
  evidence/contract/注册方式全照抄惯例）。命名随包惯例（如 path-sampling-bias，
  以包内现有前缀为准）。
- ADC 脚识别：查 parts 库/pintable 已有的 STM32 引脚知识；库没有就用最小启发
  （STM32 ADC 候选脚名表），evidence 里写明依据等级，不许假装确定。
- 范围就按草案做到分流采样链；电压分压采样等其他链留扩展点，别镀金。
- 新规则会动规则体指纹（direct+recursive 都动）：重钉并在 test_126a/test_017
  按既有格式记账。
- 真机夹具 ROBOT 必须出 2 条 WARN（R4/R5 两链）；其余夹具逐板核对无误报。
