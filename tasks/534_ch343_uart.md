# 534 — CH343 USB 转 UART 小板（绘图线 dogfood：第一个全新设计）

岳的需求原话：「在 test 工程给我画一个 CH343 的 UART 转 USB 的小板子，我要跑 6M 波特率的。
UART 那边记得拿双排排针引出来。」

性质：这是绘图线**第一次画一个不属于黄金板的全新设计**——不是复刻反激，是从需求出发。
全流程走我们自己的管线，三关（AGENTS.md 绘图交付红线）全过才算完。

## 设计裁定（主代理已拍板，子代理照做；datasheet 与裁定冲突时以 datasheet 为准并记录理由）

1. **芯片**：优先 **CH343G**（SOP-16，好焊；立创有售，商品页 item.szlcsc.com/3034092.html）。
   立创库里查不到符号/封装时退 CH343P（QFN-16）。datasheet 从 wch.cn 下，核对四件事并
   写进报告：① 是否内置时钟免晶振；② 有没有独立 VIO（UART 电平）引脚；③ V3 引脚要不要
   挂电容、挂多大；④ 标称最高波特率是否 ≥ 6 Mbps。
2. **USB 座**：Type-C 16P 母座（立创现货、mid-mount 优先）。CC1/CC2 各一颗 5.1kΩ 下拉
   到 GND（本板是 device/sink，这两颗必须有，少了不枚举）。不加 ESD 管，小板从简。
   D+/D− 直连芯片，中间不串东西。
3. **电源**：VBUS 5V → VDD。VDD 就近 100nF + 10µF 去耦。V3 按 datasheet 要求挂电容。
   VIO（若有）接法由 datasheet 的典型应用决定，写清理由（岳的对端大多是 3.3V MCU）。
   VIO 由排针对端 MCU 电轨供电，VCC 入口增加 100nF 到 GND（本图 C4 与 C1/C3 同在 ch343_power 岛；
   这是 VIO 轨退耦的图纸归属，不声称 PCB 上因此贴近芯片）。6M 是手册标称上限；
   报告必须同时披露手册对持续/全双工 ≥3Mbps 的限制，不夸成持续吞吐保证。
4. **UART 双排排针**：2×5P 2.54mm 排针（10P），把 **TXD、RXD、RTS、CTS、DTR、DSR、
   DCD、RI、VCC（UART 侧电平轨）、GND** 全部引出。引脚顺序子代理定，在图纸靠近排针处
   用文字标注每脚定义（这板子是给人类用的）。
5. **电源灯**：VBUS → LED（0603 红）→ 1kΩ → GND。
6. **命名铁律**：GND（及一切地/电源轨）用**旗标**，不许网络标签；一个旗标可汇聚多个
   就近引脚。网络标签只许出现在跨岛信号边界。本板 D+/D− 按 `localLabelObligations` 用**每脚一段独立短载体 + 同名标签**（USB1.A6/B6 与 A7/B7 各自一条短横线，不画跨两脚的 U 形线；U1.5/U1.6 用同名牌接续），电源/地只挂旗标、不挂标签。

## 流程（全部走现有管线，不许手写 JSON 落图绕过）

1. 照 `blocklib/specs/ch340_serial.{circuit,library,presentation}.json` 三件套模板写
   `blocklib/specs/ch343_uart.*.json`。`symbolRef` 的 LCSC 货号必须真实可查（报告里
   给出来源页）。每个 part 的引脚号以 datasheet/立创符号为准，**逐脚核对**。
2. `draw islands`（presentation 不声明 islands 时）→ `draw compile` → 看预览（SVG），
   自己视觉自审：每个岛说得出「这是什么、怎么接的、和网表对不对得上」。
3. 预览过关后：`draw plan` 绑 test 工程**新页**（页名 `CH343_UART`）→ `draw apply`。
   落图前先 `bridge status` 核对焦点工程逐字是 test（真机纪律 R1–R3，只碰 test/test2）。
4. 落完后：`draw lint` + 逐脚连通回验（对照 circuit 网表）+ 渲染 PNG/SVG 再视觉自审。
   任何一关不过 → 回去改 spec/管线 → 重画。三关全过才收。
5. 收尾：`checkup` 跑一遍这张图（审查线 dogfood），把发现的问题记进报告（能修的修，
   不能修的记为管线缺口）。TASKMAP 加 534 行，证据进 `evidence/534/`（不入 git）。

## 完成定义

- 报告：design 裁定逐条的落地情况、datasheet 四个核对项的答案、管线暴露的缺口清单。
