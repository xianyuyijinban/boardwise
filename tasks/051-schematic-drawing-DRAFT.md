## 三、绘制与修改的三大本质差异（新难题只在这里）

1. **无既有图纸锚定** → 布局规划是新问题：功能分区、信号流走向（左进右出）、
   电源树位置、地去向。修改从不需要回答"放哪好看"。
2. **验收从「网表恒等」变为「网表 == 设计意图」** → 意图必须显式：
   ModulePlan 自带连接清单，验收就是逐脚比对活网表与清单。
3. **规模上升** → 落点冲突/布线交叉概率指数上升。九宫阶梯在单块内够用，
   整页需要真布局引擎（切片 3 才碰，切片 1 不做）。

## 四、ModulePlan（声明式输入，模型唯一的产出物）

```json
{
  "kind": "module",
  "moduleName": "usb-uart-ch340g",
  "sheet": "bw_draw",
  "parts": [
    {"ref": "U1", "mpn": "CH340G", "value": "CH340G"},
    {"ref": "C1", "mpn": "C0603-100nF", "value": "100nF"}
  ],
  "connections": [
    {"from": "U1.4", "to": "net:VCC"},
    {"from": "C1.1", "to": "U1.4"},
    {"from": "C1.2", "to": "net:GND"}
  ],
  "layoutHint": {"flow": "left-to-right", "groups": [["U1"], ["C1"]]}
}
```

校验闸（全部工具侧，模型说了不算）：

- 每颗 MPN 在 parts.json 在册 **或**有符号库读取证据；不在册 → 拒绝并给候选
- 每颗引脚号对该器件符号真实存在（039 facts / lib_Symbol）
- 每颗值显式给出（036 先例：无默认值）
- 连接分两类：**facts 配方内**（decap/晶振负载/LDO 周边——直接采信）与
  **AI-asserted**（配方外——照画但 report 里点名，提醒用户这是模型的判断）
- 位号冲突过位号池（页面 ∪ 工程导出，036b 同款）

## 五、第一切片：空白页单功能模块绘制（5–10 器件）

流水线：

```text
AI 生成 ModulePlan
→ 工具校验闸（§四）
→ 自动布局（网格 + 信号流排序 + bbox 干涉；块内九宫阶梯推广）
→ wire_route 正交布线
→ apply 到新建 bw_draw 页（画错不污染用户图纸，用户看过再决定转正）
→ 验收双证
→ report（含 AI-asserted 连接点名）
```

验收双证（缺一 exit 3，不相信 API 返回值）：

1. **活网表逐脚 == ModulePlan 连接清单**（一脚不符即失败；036 的活网表机制）
2. **对撞验证：自己画的模块过完整规则引擎**——decap / LDO / USB CC / 值-MPN 全部应 OK。
   规则在这里从"挑错"变成"教画"：画对了规则沉默，画错了规则抓出。
   验收含反向用例：**故意画错**（少一颗 decap）规则必须 VIOLATION，抓不出 = 验收失败。

幂等与 stale（036 先例）：同一 ModulePlan 重复 apply = already_applied 零写入；
页快照失效 exit 4 零写入；超时/断连先读回绝不盲重试。

验收用例：

- 离线 ≥10：缺符号 / 假引脚号 / 缺值 / 配方外连接标注 / 落点冲突 / 位号撞池 /
  重复 apply / stale / 网表回读不符 / 布局干涉
- 真机 ≥3 模块（只碰 test/test2 窗，bw_draw 页画完即删，零残留）：
  各 applied + saved + 双证通过 + 幂等 + stale
- eval 红线：本批**不加规则不改读路径**，holdout 59/59 双 1.00 必须逐字节保持
