## 分两阶段

### 阶段 1：算法原型（新模块，不动 drawcompiler）

新建 `src/boardwise/engines/placement.py`（名字可议）：输入 = 器件清单 + 网表 + 每器件合法位姿集（从 SymbolProfile 读，照 `_accepted_poses` 的口径）+ 关系约束；输出 = 每器件 (x, y, rotation, mirror) 且满足/近似满足约束。

必须表达的概念（现在全缺）：
1. **信号/功率流方向**：默认左进右出、上进下出（源在左、负载在右）；从 grammar 的 rank/lane 语义布局继承方向提示。
2. **拓扑成簇**：围绕功率器件（变压器/开关管/整流）的引脚簇就近落位——按「共享网的脚数」加权，而不是货架顺序。
3. **位姿是搜索变量**：每器件的全部合法姿态都进搜索（不只 2 档），朝向服务走线（脚朝连接方向）。
4. **关系约束分软硬**：`same-column/right-of/near` 这类先做软约束进代价，硬约束只有「不出页/不重叠/不压标题栏」；违反软约束扣分修复（局部移动/换位/姿态翻转），不是判死。
5. **搜索方法不限**：模拟退火 / 力导向 + 贪心初始解 / 约束传播 + 回溯都可以，选你实现得了且可复现（固定种子）的。**代价函数要可解释**：每项代价有名有值，候选报告里能印出来（对照 readability 软指标的「只给原始值+理由」风格）。
