5. 边界（不在原理图页）
--------------------------------------------------------------------------------
在 test 的 PCB1（5dc38976c1fa45ce，type pcb）上调用同一条：
    boardwise bridge call 失败 [CONNECTOR_ERROR]
    sch_Drc.check threw Error: SCH_DrcUtil: doctype(3) not support check sch drc.
    This call is only meaningful on a schematic page — the focused document here is
    5dc38976c1fa45ce (pcb) — and the type package marks the whole namespace @beta
    detail: {path:"sch_Drc.check", args:{true,false,true}, focused:{uuid,type:"pcb"},
             thrown:true, errorName:"Error", errorMessage:"Error: SCH_DrcUtil: doctype(3)
             not support check sch drc", elapsedMs:0}
即：**非原理图页 = 宿主 throw**（不是返回 false / 空数组），connector 如实捕获为
CONNECTOR_ERROR，并把「焦点文档是谁」写进 message 与 detail——调用方一眼知道错在哪。
宿主文案本身带 `Error:` 前缀，connector 不再重复拼 name（勿出现 "Error: Error:"）。

结论：**能用**（计数、耗时、返回形态、幂等全部测到；`userInterface:false` 可静默跑；
非原理图页会 throw 且被如实报告为 CONNECTOR_ERROR；唯一未证实项是 UI=true 时面板是否可见，
属 connector 不可观测范围）。
