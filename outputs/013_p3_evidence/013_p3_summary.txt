§1 项1 根因（BOM 零数据行）
---------------------------
宿主自带实现（随包源码，逐字抽于 outputs/013_p3_evidence/013_p3_bom_filter_root.txt）：

  api.js（pro-api 0.3.18，扩展侧包装）
    d.filterRules = [{attr:"Add into BOM", rule:"no", checked:true},
                     {attr:"Convert to PCB", rule:"no", checked:false}]
    r && !mne(r, filterOptionArr, d) → return   // filterOptions 映射失败即返回 undefined
  mne: 对 "Add into BOM"/"Convert to PCB" 用 gne() 归一（'yes'|true→'yes'，'no'|false→'no'，
       其余→undefined→整次调用失败），把结果写进 s.rule 并 checked = true
  pro-sch sch-main.js attrsGroup2 → verify:
       e[t] = … ; n = new RegExp(r.join("|"), "i");
       if (r.length && n.test(e[t]) || …) return false   // **命中即丢行**

  ⇒ filterOptions 是**排除**规则：includeValue 是"该值出现就把这一行删掉"，不是"保留该值"。
    类型包示例 includeValue:'yes' 于是删掉了所有 Add into BOM=yes 的器件 —— 122 器件的板子
    只剩表头（152 B，列定义照样被接受）。这正是本批起点。

`property`(13) **互斥、并集 = 15 列**；真机表头逐字 15 列、序号 1..68、数量求和 122
（outputs/013_fab_bishe3/）。

§3 项2 文件名（宿主源码 + 真机）

  另加 `withSuffix()` 兜底：宿主名字为空时按 preset 名补后缀且不重复补（防 .csv.csv）。
