# 智能药箱主控板 —— 设计意图（008c 输入）

> 岳翔宇审订稿（2026-09-17 改定）。这份文档是模型选块的**唯一意图来源**。

## 这块板干什么

家用药箱的主控板：到点/远程提醒服药（蜂鸣器），监测箱盖开合与箱体跌落、倾斜，
把状态经 WiFi 上报云端（MQTT），并接受云端/手机 APP 下发的控制命令
（立即上报、上报间隔、蜂鸣器开关、复位）。

## 主控与关键器件

| 角色 | 器件 | 总线/接口 |
|---|---|---|
| 主控 | STM32G431RBT6（LQFP-64） | — |
| WiFi 模组 | ESP-01S（2.54 排针插接，MQTT 上云） | UART |
| 姿态传感 | MPU-6050（箱盖开合 / 跌落 / 倾斜检测） | I2C |
| USB 转串口 | CH340N（调试 / 烧录口） | UART |
| 电源 | micro-USB 5V 输入 → AMS1117-3.3 出 3.3V 轨 | — |
| 提醒 | 无源蜂鸣器 QMB-09B-03（2.7kHz，三极管驱动） | GPIO/PWM |
| 时钟 | 8MHz 无源晶振（X3225MOB4SI） | — |
| 人机 | 轻触按键 ×4（TS-1088）+ LED 指示 ×2 | GPIO |

## 连接器

- micro-USB（5V 输入）
- 2.54 排针：ESP-01S 插座（2x4P）、温湿度传感器模块插座（**1x4P，I2C + VCC + GND**）、
  SPI OLED 屏座（1x7P）
- **不要 1.27 连接器**；BOOT0 直接用 1kΩ 电阻下拉到地（不设跳线）

## 供电与电平

- 整板两个电平域：5V（USB 输入侧）与 3.3V（AMS1117 输出，MCU/传感器/ESP-01S）。
- ESP-01S 是 3.3V 器件，电流峰值较大，3.3V 轨的供电能力要留裕量。

## 明确不做

- 不做 PCB（007 的事）；USB 直供，**无电池、无充电电路**。
