## 0. 一句话战略

**让官方做通道，让 easyeda-agent 做壳；我们做「判断层」——离线的、有领域知识的、敢说「说不清」的判断层。**

判定标准：竞争单位是「工程师把一项任务做完要多久、返工多少」，**不是命令数量、不是规则条数、不是模型调用次数**。

## 1. 我们做什么（七条护城河，按可防御性排序）

1. **离线文件解析双轨**（结构性护城河）
   官方 CLI 和 easyeda-agent 都必须活编辑器 GUI；我们直接解析 `.epro2` / `.eprj3` / `.kicad_*`，
   headless、CI 友好、可对拍（修前修后 / 黄金基线）。这是所有「对拍验证」能力的前提：
   review-eval 评测集、compare 金标对拍、persistence 关重开对拍。叠层 Er/Df 走文件白捡
   （easyeda-agent 官方自述「阻抗从平台数据不可得」）。
2. **语义级原理图审查**（无人区）
   官方 ERC 只有引脚冲突矩阵且逐条结果无 API；easyeda-agent 没有原理图语义审查。
   我们查「电路对不对」：采样链偏置（issue #76）、LDO 压差/功耗、TVS 选型、电容耐压、
   分压输出含容差、LED 限流、USB CC 下拉、NC/must-connect 闭环、开漏上拉……
   唯一邻近威胁是 KiCad 侧的 kicad-happy（44 条 EMC 规则），EasyEDA 侧无人。
3. **设计意图合同 + 架构闭合**（产品观级）
   design-intent 槽位 + provenance 三级（user_stated > verified_recipe > ai_asserted）+
   arch 闭合规则（合同 vs 图纸对账）+ intent audit「只问一次」。
   **问的是「架构自不自洽」，不是「规则书匹配没有」**——官方和竞品连概念都没有。
4. **领域规则族**（岳的硬件 know-how 固化）
   FOC 族 11 条（功率环面积/地域/栅极线宽/热过孔阵列/回流路径）、高速族（跨分割/伴随地孔/
   差分对判定）、晶振族、MCU 供电复位族、降额族。这些是领域知识，不是通用规则。
5. **诚实性机制**（产品级设计）
   三态 verdict（complete / complete-with-open-items / incomplete），判不了不许写「通过」；
   need-datasheet 缺手册不过；triage 分诊重跑不丢；退出码 3 =「说不清」（不是「干净」）。
6. **写操作安全模型**
   bridge 动作白名单 + 风险四级闸（read/write/create/dangerous）+ 写前预览→授权→回读 +
   超时先回读不盲重试 + 热更新逐窗验证。竞品「给 AI 全权」，我们「戴镣铐跳舞」——
   对工程师用户这是卖点。
7. **KiCad + EasyEDA 双解析器统一规则引擎**
   easyeda-agent 只做 EasyEDA；kicad 系工具只做 KiCad。双吃的是只有我们。

## 2. 我们不做什么（硬边界）

| 不做 | 理由 | 例外/边界条件 |
|---|---|---|
| **通用工艺 DRC 重造**（间距/线宽/孔径/连通性） | 官方内置且权威、直连板厂工艺参数；重造是拿短板打主场 | 语义层的间距（跨安规边界、跨分割）仍做——判的是「为什么该分开」不是「够不够 mil」 |
| **通道层硬拼**（CLI/MCP 形态之争） | 官方 `easyeda-client-cli`（V4.1.60+ 内置、可执行任意 JS）有主场；通道是手段不是产品 | 保留 bridge 双轨（离线优先）；通道只做到「够用、安全、可对拍」 |
| **全自由绘制**（任意电路一键成图） | 大家都画不及格（岳亲口认证 easyeda-agent 画的「是给 AI 看的，不是给人类看的」）；自由绘制是 bet 不是产品 | 守「语法块 + 可读性门禁」窄路：认出拓扑、画成人类可读、门禁敢拒 |
| **PCB 自动布局布线** | 本轮产品路线明确不进入（2026-09-18 路线）；手工布局是工程师主权 | PCB 侧做**审查**与**判定**（29 条规则），不做自动 PLACER/ROUTER |
| **SPICE 仿真** | 岳 2026-10-17 裁：等**原理图绘制过关** + **041 跨板网络**搞定后再开 | 前置条件未满足前，不投入仿真 |
| **器件库商业数据**（BOM 报价/库存/替代料） | 双方都有、是数据生意不是判断生意 | BOM 导出/LCSC 解析维持现状，不投入 |
| **多用户/协作/云服务** | 与「单人工程师本机 harness」的产品形态冲突 | — |
| **规则条数竞赛** | 条数是虚荣指标；判据是「任务完成时间与返工」 | 新增规则必须有真实踩坑或测量支撑（见 `docs/testing-doctrine.md`） |
| **对 AI 说「通过」的省事路径** | 诚实性是产品根基（护城河 5） | 任何「让报告看起来干净」的优化一律否 |
| **批量查询料号暴露设计信息** | 「这颗 MCU + 这颗变压器 + 这颗驱动」的组合能反推产品，比企业名字更隐蔽 | L2 查询只含**单个 MPN**，不带网名/位号/工程名/电路功能；企业项目可整体关闭 L2 |
| **AI 检索到的参数驱动安规结论** | 网上错版与替代料的 datasheet 参数差异可以很大 | `machine_verified` 只驱动载流/降额/间距**计算**；安规与隔离结论必须 `verified` |

判定「这是不是我们的活」的两个问题：
1. 它是不是**判断**（而不是通道/数据/执行）？
2. 它是不是**离线可验证**（不依赖活 GUI、可对拍）？
两个都「是」才进核心；一个「是」进辅助；都不是 → 不做。

## 3. 撞车区（官方/竞品已覆盖，别拼刺刀）

| 能力域 | 官方/竞品现状 | 策略 |
|---|---|---|
| 基础工艺 DRC | 官方内置 + 官方下单 DFM 扩展（18+7 项） | **避让**：不重造；我们的价值在语义层 |
| 网络长度/差分对/等长只读报告 | 官方 eext-export-design-report；easyeda-agent pcb report | **错层**：他们「报」我们「判」（等长门禁、跨分割、伴随地孔——他们都没有判定层） |
| CLI/MCP 通道 | 官方 easyeda-client-cli（V4.1.60+）；easyeda-agent 三形态 | **认栽不硬拼**：保离线双轨，通道够用即可 |
| AI 自由绘制/自动布线 | easyeda-agent autolayout/route-short/Freerouting；官方 AI 放置扩展 | **收窄**：守语法块窄路 |
| BOM 导出 / LCSC 解析 | 双方都有 | 维持，不投入 |
| 原理图↔PCB 一致性 | 第三方扩展「设计一致性审查」已在广场 | 浅撞，我们更深（档内回退、库件 id 反查） |

## 4. 威胁雷达

| 威胁 | 实质 | 应对 |
|---|---|---|
| 官方 easyeda-client-cli + MCP | 官方亲自下场做通道层，纯壳层会被吸干 | 官方做「通道」不做「判断」；模型越强、通道越好用，我们的 harness 越是放大器 |
| kicad-happy（KiCad 侧 ★1k+） | 44 条 EMC 规则、SPICE、热分析、5800+ 语料验证 | 对标学习清单：EMC 规则库规模、SPICE testbench 生成、制造发布闸 8 类；EasyEDA 侧它过不来 |
| AI 平替论 | 裸模型 + skill 变强 | 平替的是「裸模型 + skill」，平替不了「解析器 + 规则引擎 + 意图合同 + 证据链」；harness 是乘数 |

## 5. 这份文件什么时候改

- 上游出现新能力（官方新版本、easyeda-agent 新 release、kicad-happy 新规则族）→ 先改「撞车区」，
  再决定排期要不要跟；
- 岳改产品意图（例如 SPICE 解冻、PCB 自动布线解冻）→ 改「不做什么」并写日期与理由；
- 护城河被证明不成立（例如离线解析不再有优势）→ 改「做什么」并把证据链写在这条下面。

**改动必须留痕**：日期 + 谁裁 + 一句话理由。没有理由的边界改动视为无效。
