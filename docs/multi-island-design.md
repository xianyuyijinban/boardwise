# 多岛布局设计（520i）

- 日期：2026-10-20
- 定调来源：岳，亲自拍板（「多岛是布局基本单元，粒度到摆不下的去耦电容；大拓扑自己多岛；岛间靠网络标签」）
- 机制地图：`evidence/520h/module-map.md`
- 前置批次：520A2–520G（chain 侧向放宽 / 旗标席位 / 禁镜像 / 标签降级 / stub 范围）

---

## 1. 定调（一字不改记下来）

- **岛是布局的基本单元**，不是「两岛」，是**多岛**。
- 粒度：从「一个功能模块」到「**一颗摆不下的去耦电容**」都可——摆不下的局部就独立成一个岛。
- 一个大的拓扑电路（反激、LLC、PFC）自己就是**多个岛**。以后产品里多个器件模块，**每个模块就是一个岛**。
- 岛与岛之间**靠网络标签接回**，不是靠长导线。

**一句话规则：岛内地线连，岛间名字接。**

## 2. 概念分层（先立词，防止撞车）

| 词 | 含义 | 现状 |
| --- | --- | --- |
| **net-island** | 一条网按命名聚成的几个子节点（连通性） | 现有（`069 sec.2`），`src/` 里「island」只有 6 处、全是注释 |
| **layout-island** | 电路按功能/密度分成的几个**布局块**（本设计） | **今天没有载体** |

布局岛的载体：**新增 `islands[]` 键，只被布局层消费**。不改 `PresentationSpec.modules`
的语义——`modules` 是语法绑定的作用域（flyback 现在 1 个 `flyback_core`），动它会触发 113 的拒绝史。

## 3. 三条路线与选择

| 路线 | 内容 | 代价 | 判定 |
| --- | --- | --- | --- |
| A | 岛 = `modules[]`，复用 `pagecompiler`（各模块各编译、刚体打包） | flyback 语法**拒绝片段**：113 拆 5 个、0 个能绑（要两族地 + ≥4 网变压器）；要么拆子语法，要么给 flyback 加「片段模式」 | **否** |
| B | 一个 module，在求解器（chain+shelf）里改出布局岛 | 动 114/115/116/117/120 一路手术出来的 chain+shelf，回归面极大 | **否**（本阶段） |
| **C** | **一份绑定电路 + 声明式 `islands[]`**（布局层自己分块） | 不碰语法绑定；复用 520E/F 的 stub+name 作岛间连接；每岛用现有 chain+shelf（小规模） | **选** |

选 C 的核心理由：flyback 的**语法**要的是「整只反激」（这是它可读的前提），
而岳要的**布局**是「几块分开的岛」。这两件事不冲突——**绑定保持整只，布局自己分块**。
C 正好让这两层各干各的。

## 4. 编译四步（C 的形状）

```
绑定（照旧，整只反激）
  → ① 每岛布局：岛内 chain+shelf（短链、低密度），岛内引脚用 wire 连
  → ② 岛摆放：每岛外接框当刚体，按网格打包进页，岛间留边界通道
  → ③ 岛间连接：跨岛网 → 每端一个标签（520E/F 的 stub+name）；同岛网 → wire
```

- **岛间连接判定**：一条网的引脚**跨 ≥2 个岛** → 该网走标签；全在一岛内 → wire。
  这就是 `_expression_style` 的 `crossModule` 分支（`drawcompiler.py:5652`）的准确用法，不用新造。
- **每岛布局**：复用现有 chain+shelf。岛小（5~10 件），链短、密度低，
  竖条/文字爆密这两类今晚的病在「一岛只有几件」的尺度下**自然消失**。
- **岛摆放**：借 `pagecompiler` 的刚体打包思路（`pagecompiler.py:1290` 起），
  但在**一份电路的布局层**做，不是按模块分页编译。
- **标签机制**：520E（降级 + 显式记账）+ 520F（每脚一根 stub）。岛间一条网
  在两岛的边界各挂一个名字，网表靠同名合并——与岳手画的「RCD 单独拎一块」同构。

## 7. 岳的裁定（2026-10-20，已拍板）

1. **岛分法暂定**（可改）：正边 / 副边 / 反馈 / 变压器（跨岛元素）/ 控制器 + 去耦。
2. **岛间的网一律标签，不建议跨岛接线**——没有例外。
   规则因此是干净的：**岛内地线连，岛间名字接**，连「主环关键网允许整线」的口子都不留。
   `pagecompiler` 的 `main_path_wire` 先例**不采用**。
   **细化（岳 2026-10-20 二裁，针对 520k 副边空壳）**：规则按**段**算，不按网算——
   **跨岛网在本岛的那一段，用导线连起来；岛与岛之间那一跳，用标签接。**
   一条网**既在岛内走线、又在岛间挂名**，两件事不矛盾。按「网」理解会把副边掏空
   （`SEC_12V`/`SEC_GND` 全跨岛 → 副边岛内零导线），按「段」理解才对。
   因此 520j 的 `cross_island_nets` 语义要跟着改：跨岛网 ≠ 「全标不连线」，而是
   「**每岛走本段 + 边界一个名**」。
3. **岛来源**：手写进 spec + grammar 按 role 推导，**手写覆盖推导**。
4. **顺序：先打地基**（520j → 520k → 520l → 520m），不先出形状。

## 8. 明确不做

- 不拆 flyback 语法成子语法（那是路线 A）。
- 不动 114–120 的 chain+shelf 主干（那是路线 B）。
- 不在本阶段做「岛自动拆分」——`islands[]` 先声明式，自动拆分另立题。
- 不让岛间网静默降级——一律显式记账（520E 的规矩）。
