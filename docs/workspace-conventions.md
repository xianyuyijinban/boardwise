# 工作区目录与证据约定

> 540A（2026-10-25）建立。本文约束**仓库内开发、探针、审查产物和实验的落点**；
> 真实工程身份与写入纪律仍以 `.agents/skills/boardwise/SKILL.md` 为准。
> 本文不授权移动、删除或任何 git 写操作。

## 1. 固定落点

| 内容 | 固定位置 | 保存与入库口径 |
|---|---|---|
| 产品源码、测试、任务书、权威文档 | `src/`、`connector/`、`dsh-plugin/`、`tests/`、`blocklib/`、`docs/`、`tasks/`、`tools/`、`scripts/`、`packaging/` 及既有根配置 | 正常跟踪；不得用整理名义覆盖他人未提交修改 |
| 长期验收依据 | `evidence/<批号>/`（建议 `report.md` + `probes/` + `raw/` + SHA-256） | **默认本地保留、gitignore**；未跟踪不等于垃圾。确需入库的证据须单独做敏感信息审查并取得 git 授权；已有跟踪文件不动 |
| 可重跑审查/工具产物 | `outputs/review/<批号>/`；既有 `outputs/<任务或工具>/` 可继续使用 | 默认本地、可重跑；已有跟踪文件不动。测试引用本地产物时必须能在缺失时如实 skip，不能假定每台机器都有 |
| 可保留实验的设计/源码/说明 | `experiments/<名称>/` | 只放可公开的实验说明、配置与源码，须有 README 说明问题、输入、复跑命令和结论；真实工程与生成物不放这里 |
| 实验生成物 | `outputs/experiments/<名称>/` | 本地、可重跑；不混进实验源码 |
| 一次性探针与中间态 | `.tmp_<批号>/`，建议 `probes/`、`raw/`、`mutations/`、`review/` 子目录 | gitignore；不得在仓库根散放 probe/debug 文件。是否保留由任务书决定，不能按名字整批回收 |
| pytest 临时树 | 每批唯一 `.tmp_pt_<批号>` | gitignore、可再生产；并行前场不得共用，全量一次只跑一轮 |
| pytest/Python 缓存 | `.pytest_cache/`、`__pycache__/` | gitignore、可再生产；只在没有相关进程运行时才能申请回收 |
| connector/DSH 依赖与构建物 | 各工具既有 `node_modules/`、`dist/`、`lib/`、输出目录 | 严格按各目录既有跟踪规则；`dsh-plugin/lib/` 是跟踪产物，不能当普通 build 垃圾 |

**根目录不再新增散装探针、临时 JSON/TXT、一次性脚本或 hunt 目录。** 新文件先问“它属于上表哪一格”，
答不出就不要创建。已有历史文件不因本文自动搬家。

## 2. 保留 / 归档 / 可回收

- **保留**：当前源码与任务文档、未提交工作、被任务/测试/文档引用的证据、真实会话核实区、
  唯一历史副本、活动 worktree、明确标记的证据档案、黄金板与既有 fixtures。
- **归档**：仍有历史价值但不再参与日常工作的材料。归档必须写清来源、目标路径和敏感信息审查；
  未经岳确认不移动。真实会话/网表等敏感材料不得因“归档”被放进公开文档或 fixtures。
- **可回收**：已证明可由测试/构建再生成，或已证明只是单次残留的内容。回收前重新枚举、
  确认没有进程使用、取得岳对该批路径的明确同意，并一律走 Windows 回收站。

`untracked`、`ignored`、`.tmp_` 前缀、文件时间为旧，**任何一项单独都不是回收依据**。
`归档` 也不等于 `可回收`。

## 3. worktree 是独立边界

清理任何 `.tmp_*` 前先看 `git worktree list --porcelain`。**注册 worktree 绝不能按普通临时目录处理。**
主仓与 `E:\boardwise-wt520` 证据档案不动；旧实验 worktree 必须逐个核对未提交 diff、未跟踪/忽略文件、
独有证据与任务记录。`git worktree add/remove/prune` 是 git 写操作，必须另获明确批准；
不能用回收站绕过 worktree 的身份与历史核查。

## 4. 代理执行规则

1. 一次性探针写 `.tmp_<批号>/probes/`，原始输出写 `.tmp_<批号>/raw/` 或任务指定的证据区；
   不在根目录创建“临时一下”的文件。
2. `checkup` 等审查产物用 `outputs/review/<批号>/`；需要长期引用的结论、原始读数索引与哈希，
   由任务书明确收进 `evidence/<批号>/`，不把整份真实工程复制进去。
3. pytest 永远显式给独立 basetemp。测试辅助函数需要额外临时目录时，必须显式使用当次
   `tmp_path`/basetemp 或调用方指定目录；不得回退到进程全局 tempdir 后在仓根乱落。
4. `evidence/` 与 `outputs/` 的**既有跟踪文件保持跟踪**；新增忽略规则不会也不应取消跟踪它们。
   任何 `git add -f` 仍是 git 写，逐次询问。
5. 每批结束只报告产物路径与分类；是否归档/回收另走确认，不在交卷时顺手清理。
6. 不碰 `outputs/011e*`、`014_*`、`015b_*`、`016_*`、真实工程容器与 `tests/fixtures/` 既有夹具。

机器钉：`tests/test_workspace_conventions.py` 检查上述 ignore 边界、源码/实验说明不被误忽略，
以及 520 hunt 测试不再使用进程全局临时目录回退。
